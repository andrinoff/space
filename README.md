A stunning, real-time, interactive 3D galaxy visualization built entirely with web technologies. This project uses Three.js to render 100,000 particles and custom GLSL shaders to create a dynamic and mesmerizing space exploration experience right in your browser.

## ✨ Features

-   **Massive Particle System:** Simulates a galaxy with 100,000 individual particles, each with its own properties.
-   **Procedural Generation:** The spiral galaxy structure is generated procedurally, creating a unique and organic look.
-   **Custom GLSL Shaders:** Vertex and Fragment shaders are used for advanced animations, including the spiral motion and a "warp speed" effect.
-   **Interactive Controls:**
    -   **Rotate:** Click and drag your mouse to rotate the galaxy and view it from any angle.
    -   **Warp Speed:** Hold the mouse button down to activate a streaking warp effect that pulls you through the stars.
-   **Dynamic Coloring:** Particles are colored based on their distance from the galaxy's core, transitioning from a warm orange to a cool blue.
-   **Responsive Design:** The canvas and visualization automatically adapt to the size of your browser window.

## 🚀 How to Use

1.  Clone or download this repository.
2.  Open the `index.html` file in any modern web browser (like Chrome, Firefox, or Edge).
3.  That's it! You are now exploring the galaxy.

### Controls

-   **Rotate:** Click and drag the mouse.
-   **Warp Speed:** Hold the mouse button down.

## 🛠️ Technologies Used

This project is built with:

-   **HTML5:** For the basic structure of the web page.
-   **CSS3:** For minimal styling and layout.
-   **JavaScript (ES6):** For the main application logic, interaction, and scene setup.
-   **[Three.js](https://threejs.org/):** A powerful 3D graphics library that simplifies working with WebGL.
-   **GLSL (OpenGL Shading Language):** Used to write the custom vertex and fragment shaders that control the appearance and behavior of each particle.
